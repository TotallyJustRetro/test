# HANDOFF (PipeClean / Dr Mario Launcher) — SM83 static recompiler + SDL launcher for Dr. Mario, Super Mario Land (SML), SML2
- **Done:** C lifter+runtime (`runtime/`), launcher UI (`launcher.c`, `ui.c`), 3 game tabs, palettes, bg images/GIF, romhacks (IPS/BPS/UPS), texture packs+export, filters, controls, DualSense (LED/rumble/speaker/events), menu music/SFX, Windows exe built via llvm-mingw (Linux-tested only).
- **Widescreen:** PPU renders up to 256px (`ppu_set_wide`, `widescreen.c`); per-game slider in Display tab; gates show bars on menus/maps. SML works: 235px, in-memory ROM patches (spawn +16k px at 0x24A5/0x24C0, despawn window at 0x2584, trampolines at 0x3FE4) – verified no mid-screen pop-in.
- **SML2 widescreen (done, headless-tested):** activation window bank2@0x401C + sprite draw cull bank3@0x4023/4077 both patched. Pop-in at original right edge gone; OAM write ptr peaks 0x3C (limit 0xA0); sliders 10-100% all install. See widescreen.c `wide_install` for details.
- **Three-game recomp (done):** all three games now statically recompiled. Bank functions renamed `recomp_bankN_sml` / `recomp_bankN_sml2` to avoid linker collision. Old bare `generated/game.c` / `generated/interp.c` removed. Dispatch via `generated/dispatch.c`. `make regen` rebuilds from ROMs.
- **PipeClean rename (done):** window title, ini file (`pipeclean.ini`, falls back to old `dr_mario_launcher.ini`), exe name (`PipeClean.exe`), in-launcher header logo (64×64 compiled-in RGBA, `runtime/logo.c`). Regenerate logo: `python3 tools/make_logo.py` (needs Pillow).
- **Next:** build with SDL on Windows, test all three games, check SML2 beyond level 1 (bosses, auto-scroll, dense sprite areas), update GitHub Actions to install Pillow for logo regen.
- **Decisions:** ROM never modified on disk; patches verify expected bytes else fall back to normal screen; wide gate SML = IE timer bit, SML2 = window HUD wx==7&&wy==0x88; ROMs/generated code not committed (copyright) – regenerate: `python3 tools/recomp.py roms/dr_mario.gb -o generated --listing`.
- **Build:** `make ROM=roms/dr_mario.gb BUILD=build_sdl SDL_LIBS=-lSDL2`; Windows: llvm-mingw + `EXTRA_LIBS="-lshell32 -lole32 -lcomdlg32 -luuid"`.
- **Dev tools:** `--headless --frames N --script s --wide PCT --dump-ppm/--dump-ram/--watch LO-HI`, `GBL_POPIN=xmin` pop-in detector, `tools/dis.py rom start end bank`, UI shots via `GBL_SHOT/GBL_TAB/GBL_SIZE` + dummy SDL drivers.
- **Files in play:** runtime/{ppu.c,widescreen.c,launcher.c,app.c,games.h,rom.c,emu.c,main.c,settings.c}, tools/{recomp.py,dis.py}, README.md.
- **Untested:** real-Windows audio smoothness, DualSense hardware, SML GIF animation wiring, Blargg regression after refactor.
